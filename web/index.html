Install in Chrome

Load the extension/ folder as an unpacked extension in under a minute. No store listing required.

  1. Get the code

    Download the latest ZIP, or clone the repo.

    Download ZIP Open repo 
    git clone https://github.com/hamzaakram007/spoiler-shield-ext.git
cd spoiler-shield-ext
  2. Open Chrome extensions

    Go to chrome://extensions and turn on Developer mode (top right).

  3. Load unpacked

    Click Load unpacked, then select the extension/ folder inside this repo — not the repo root and not web/.

  4. Pin and configure

    Pin Spoiler Shield from the puzzle menu. Use the popup toggle, then open Settings to add the spoilers you want blurred.

Tip: After pulling updates, open chrome://extensions and hit the refresh icon on Spoiler Shield so the new content script loads.

What it does

Your keywords, your feeds — blur until you decide to look.

  • Blurs matching titles and nearby thumbnails with a reveal button
  • Re-scans SPA feeds as you scroll or navigate
  • Syncs keywords across Chrome via chrome.storage.sync
