How it works

One job: hide spoilers until you choose to look.

  1. You add keywords

    Phrases you care about — endings, twists, character names.

  2. Feeds get a soft blur

    Matching titles and nearby thumbnails blur on YouTube, Reddit, and X.

  3. You tap Reveal

    When you are ready, one click clears that post. Nothing leaves your browser.

Install in Chrome

Load the extension/ folder as an unpacked extension in under a minute. No account required.

  1. Get the code

    Download the latest ZIP, or clone the repo.

    Download ZIP View source 
    git clone https://github.com/hamzaakram007/spoiler-shield-ext.git
cd spoiler-shield-ext
  2. Open Chrome extensions

    Go to chrome://extensions and turn on Developer mode (top right).

  3. Load unpacked

    Click Load unpacked, then select the extension/ folder inside this repo — not the repo root and not web/.

  4. Pin and add keywords

    Pin Spoiler Shield from the puzzle menu. Use the popup toggle and quick-add, or open Settings to manage your full list.

Tip: After pulling updates, open chrome://extensions and hit the refresh icon on Spoiler Shield so the new content script loads.

Privacy, in plain words

  • Your keyword list stays in your browser (Chrome sync if you use it).
  • NeonGulf never receives your keywords, history, or feed content.
  • The extension only runs on YouTube, Reddit, and X — plus storage for your settings.
  • No accounts, ads, or trackers.
